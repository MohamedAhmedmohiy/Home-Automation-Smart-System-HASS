System Architecture

Industrial-Grade Physical Computing. No Black Boxes.

Every HASS module is inspectable, documented and serviceable — from the ESP32 controller to each solid-state relay channel.

Module 01 · CoreESP32

Central Controller Unit

Dual-core ESP32 orchestrating relays, sensors and Wi-Fi telemetry with deterministic local logic.

Module 02 · Actuation4 CH

Smart Solid-State Relay Board

Four isolated channels for silent, zero-crossing appliance switching.

Module 03 · SensingDHT22

Multi-Sensor Telemetry Array

Temperature, humidity and current sensing feeding automation rules in real time.

Module 04 · NetworkWi-Fi

Local Network Fabric

Wi-Fi LAN control with optional Firebase sync for remote access from the mobile app.

The Problem

Households Bleed Up to 23% in Unmonitored Standby Loads.

Devices left on standby silently draw power around the clock with no visibility or control.

  • No per-appliance monitoring
  • Manual switching only
  • Cloud plugs fail when the internet drops
The HASS Solution

Deterministic Circuit Cutoff & Millisecond Visibility.

HASS measures every channel and cuts idle loads automatically from the local ESP32 controller.

  • Per-channel power readings over Wi-Fi
  • Automatic cut-off rules and schedules
  • Works offline on the local network
